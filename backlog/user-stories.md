# User Stories
- As a Security PM, I want all stakeholder requests in one intake table so I can triage demand consistently.
- As a GRC Lead, I want automated evidence reminders so control owners submit proof on time.
- As a SecOps Lead, I want incident prioritization based on asset criticality so response effort aligns with business risk.
- As an Engineering leader, I want vulnerability SLA exception visibility so accepted risks are explicit.
- As a CISO staff partner, I want a decision log so executive tradeoffs are documented with owners and due dates.
- As a Program Manager, I want adoption signals after release so shipped work is measured by usage, not output.
